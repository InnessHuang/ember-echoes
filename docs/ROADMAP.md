| 阶段 | 状态 | 主要交付物 | 验收条件 |
| --- | --- | --- | --- |
| 1：设计规范与工程基础 | 已完成（Task 01） | README、设计/数值/测试/路线文档；Next.js + TypeScript + Tailwind；Vitest 入口；占位首页 | 文档参数一致；lint、类型检查、生产构建及首页请求通过；如无测试如实说明；没有战斗实现 |

| 3：浏览器可玩战斗界面 | 已完成（Task 03；Chromium 验收通过） | 意图、生命、能量、四种行动和结果展示 | 单场可完成；资源不足拒绝行动且状态不变；页面展示与引擎状态一致；界面不复制计算规则 |
| 4：三场战斗与成长流程 | 已实现（Task 05；待审核） | 轻型→重型→Boss，升级选择、生命继承、失败重开与通关 | 升级时点正确；三战可走通；无自动回血；重开完全重置；Boss 胜利直接通关，不再升级 |
| 5：Python 批量模拟与数据分析 | 计划中 | Python 入口、同版本配置、策略比较、敏感性分析与数据产物 | 固定轨迹与 TS 逐步一致；参数、策略、指标及运行方式可复现 |

| 7：部署和作品集整理 | 计划中 | 可访问 Demo、部署说明、规则与分析作品集材料 | 外部可访问且无秘密泄露；设计决策能追溯到规则、实验与结果；如实列出限制 |
