# 开发路线

仅阶段 1 属于 Task 01。阶段完成需有实际验收证据，不因编写计划而宣称功能完成；后续阶段均需负责人授权后开始。

| 阶段 | 状态 | 主要交付物 | 验收条件 |
| --- | --- | --- | --- |
| 1：设计规范与工程基础 | 本次交付，待负责人审查 | README、设计/数值/测试/路线文档；Next.js + TypeScript + Tailwind；Vitest 入口；占位首页 | 文档参数一致；lint、类型检查、生产构建及首页请求通过；如无测试如实说明；没有战斗实现 |
| 2：纯 TypeScript 战斗规则引擎 | 计划中 | 集中参数配置、独立规则模块、Vitest 单元测试 | 先确认跨战斗能量约定；行动、资源边界、胜负和 Boss 计数覆盖测试；不依赖 UI |
| 3：浏览器可玩战斗界面 | 计划中 | 意图、生命、能量、四种行动和结果展示 | 单场可完成；资源不足不可操作；页面展示与引擎状态一致；界面不复制计算规则 |
| 4：三场战斗与成长流程 | 计划中 | 轻型→重型→Boss，升级选择、生命继承、失败重开与通关 | 升级时点正确；三战可走通；无自动回血；重开完全重置；终场按规范处理 |
| 5：Python 批量模拟与数据分析 | 计划中 | Python 入口、同版本配置、策略比较、敏感性分析与数据产物 | 固定轨迹与 TS 逐步一致；参数、策略、指标及运行方式可复现 |
| 6：数值迭代与结果验证 | 计划中 | 基线数据、问题假设、参数变更与前后对照报告 | 每次变更有测试证据与指标对照，说明收益、代价和局限，回归无规则偏差 |
| 7：部署和作品集整理 | 计划中 | 可访问 Demo、部署说明、规则与分析作品集材料 | 外部可访问且无秘密泄露；设计决策能追溯到规则、实验与结果；如实列出限制 |
