# Ember Echoes（余烬回响）游戏设计

状态：Task 01 设计基线，玩法尚未实现。精确参数、结算与边界以 [数值规范](NUMERICAL_SPEC.md) 为准。

## 定位与设计边界

面向中国大陆 2027 届校招的数值策划作品集，通过浏览器可玩的原创回合制战斗 Demo，展示机制拆解、规则设计、参数配置、数值模拟、策略比较、敏感性分析和基于证据的平衡迭代。规模以可验证的小型原型为限，不以大型商业游戏为目标。

借鉴成熟回合制 RPG 与 Roguelike 的局部机制：可预测意图、资源取舍和战后成长；角色、技能、敌人、数值与关卡设计均为原创。不复制现有作品的内容、资产或完整系统。负责人主导游戏设计、数值、测试方案和结果分析，Codex 辅助开发；代码以清晰、可维护、可验证为原则。

## 核心循环与行动

回合开始展示敌人当前行动意图 → 玩家先行动 → 若敌人仍存活则执行敌方行动 → 判定结果或进入下一回合。玩家管理生命与能量，通过四种行动权衡输出和生存：

| 行动 | 基础效果 |
| --- | --- |
| 普攻 | 12 点伤害，不消耗能量 |
| 重击 | 25 点伤害，消耗 2 能量；不足时不可用 |
| 防御 | 当前敌方攻击减伤 12，当前行动增加 1 能量 |
| 蓄能 | 不造成伤害，增加 2 能量 |

能量始终限制在 0 至当前上限。防御不跨回合。初始玩家生命 100/100，能量 2/4。生命跨战斗保留，不自动恢复；新战斗能量如何初始化尚未确定，见数值规范待确认项。

## 敌人与三场流程

1. 轻型敌人：生命 42，普通攻击 9。
2. 重型敌人：生命 60，普通攻击 13。
3. Boss：生命 120，普通攻击 12；每第三次实际执行的敌方行动为 22 点特殊蓄力攻击，提前展示意图，也受防御影响。

胜利 → 从三个固定选项选择一个升级 → 进入下一场。失败立即结束本轮，重新开始恢复全部初始属性与升级状态。

## 升级

| 选项 | 选择后效果 |
| --- | --- |
| 锋刃 | 普攻与重击伤害各 +3 |
| 蓄能核心 | 能量上限 +1 |
| 强化护甲 | 防御减伤 +6 |

升级选择后生效并影响后续战斗，不自动回血。每次胜利固定展示这三个选项，不随机掉落。

任务同时规定“每场胜利后选择升级”和“三场战斗”。保留每场胜利均选择升级的约定：第三场后仍选择，随后结束挑战，不生成第四场；末次升级无后续战斗收益。终局界面后续实现。
